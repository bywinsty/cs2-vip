# Security policy

## Supported versions

Security fixes are developed and validated on the `dev` branch. Stable releases receive a fix only after the same build, attestation, and runtime gates pass. The supported runtime platform is Linux x86-64.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Submit a private report through [GitHub private vulnerability reporting](https://github.com/bywinsty/cs2-vip/security/advisories/new) with affected commit/release, reproduction steps, impact, and any relevant logs.

Do not include production credentials, database contents, Steam tokens, or private server data. Maintainers will coordinate disclosure and remediation in the private advisory.
